# Contact Book 📒

A simple Contact Book application developed using Python.

## About the Project

This project is used to manage contacts.
Users can add, view, search, update, and delete contact details.

## Technologies Used

- Python

## Features

- Add a contact
- View contacts
- Search for a contact
- Update contact details
- Delete a contact
- Exit the application

## How to Run

Run the following command:

```bash
python contact-book.py
